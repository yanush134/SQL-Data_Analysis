# SQL Data Analysis

## 📌 Project Overview

A practical SQL project focused on analyzing **sales, customers, and product performance** using PostgreSQL.

The project demonstrates how SQL can be used to answer business questions, identify trends, analyze customer behavior, and evaluate product performance.

## 🛠️ Tools & Technologies

* PostgreSQL
* SQL
* DBeaver

### SQL Techniques

* JOINs
* CTEs
* Window Functions
* `CASE WHEN`
* Aggregations
* Date & Time Functions
* `LAG()`
* Cumulative Analysis
* Year-over-Year Analysis
* Customer Segmentation

## 📊 Analysis

The project includes:

* **Time-Based Analysis** — sales, customers, and quantity trends over time
* **Cumulative Analysis** — running totals and average metrics
* **Product Performance** — YoY comparison and performance evaluation
* **Part-to-Whole Analysis** — product contribution to total sales
* **Customer Segmentation** — grouping customers by purchasing behavior
* **Customer Report** — customer-level KPIs and purchasing activity
* **Product Report** — product-level performance metrics
